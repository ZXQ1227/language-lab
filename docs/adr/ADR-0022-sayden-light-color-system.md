# ADR-0022: Sayden light color system

- Status: Accepted
- Date: 2026-11-19

## Decision

- Define the Sayden palette in the desktop Tailwind theme. Use semantic color
  tokens in components for surfaces, typography, controls, conversation and
  feedback. Ship a single light theme.
- Keep the supplied brand swatches and add accessible text and filled-control
  tones. Brand blue serves accents, focus and progress. Primary actions and
  learner replies use a slightly deeper blue with white text. Give controls
  a visible keyboard focus indicator and a contrasting input boundary.
- Use lavender for partner messages and AI commentary, yellow for hints and
  incomplete goals, green for verified goals, and rose for corrections.
  Keep speaker names, feedback labels and goal marks in the interface.
- Reserve gradients for compact brand marks and avatars. Keep application
  backgrounds, buttons and form fields solid.
